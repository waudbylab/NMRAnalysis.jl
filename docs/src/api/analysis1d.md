# API: Analysis1D

The 1D analysis framework: the entry points (`relaxation1d`, `diffusion1d`, `tract`,
`calibration1d`, `kinetics1d`), the data types they build (`Trace`, `Planes`, `Region`,
`Dataset1D`), the experiment types and their interface hooks, and the interactive window.
See [Creating New 1D Analyses](../advanced/creating_1d_analyses.md) for how these fit
together.
