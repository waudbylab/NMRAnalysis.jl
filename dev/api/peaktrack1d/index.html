API: PeakTrack1D

Peak tracking across a series of 1D spectra: the entry point peaktrack1d, the analysis it returns (PeakTracker), the picking model (Pick, Multiplet, Tracks), and the processing of time-domain data. See Peak tracking for how to use it.

NMRAnalysis.PeakTrack1D — Module
PeakTrack1D

Interactive picking of peak positions across a series of 1D spectra, drawn as a stack. Each entity is a multiplet made of one or more lines, and each line holds at most one pick per plane. A reference multiplet, picked like any other, lets the spectra be aligned and the shifts referenced.

The picking model (tracks.jl), the peak finding (peaks.jl) and the brush geometry (view.jl) are plain functions of plain data, and are what the tests exercise. NMRData is touched only when the spectra are loaded or processed (series.jl, processing.jl), and Makie only in drawing and the window.

NMRAnalysis.PeakTrack1D.IndirectReference — Type
IndirectReference(frequencies, label)

Shifts on the IUPAC unified scale, referenced indirectly to DSS picked in a ¹H analysis of the same samples. frequencies holds the frequency of 0 ppm on the ¹H scale in each plane (Hz, NaN where DSS was not picked), and label names the ¹H reference.

On the unified scale the frequency of 0 ppm for nucleus X is Ξ_X times that of ¹H in DSS, so a line at frequency ν has

δ = (ν / (Ξ_X ν₀(¹H)) − 1) × 10⁶

where ν = bf (1 + δ′ × 10⁻⁶) for a line at apparent shift δ′ on an axis whose 0 ppm is at bf. Because each spectrum's own bf enters, the result does not depend on how the X spectrum was referenced when it was processed.

Harris, Becker, Cabral de Menezes, Goodfellow and Granger, Pure Appl. Chem. 73, 1795 (2001); Harris et al., Pure Appl. Chem. 80, 59 (2008).

NMRAnalysis.PeakTrack1D.Processing — Type
Processing(fids; lb=1.0, zerofill=2, solvent=:auto, phase=:auto)

Time-domain data and how they become the spectra shown: one FID per experiment (1D or pseudo-2D), exponential line broadening lb (Hz, adjustable afterwards), zero-filling, solvent suppression as in autoprocess, and one (p0, p1) phase correction per experiment (degrees, TopSpin's convention) with where it came from:

  • :auto: autoprocess's automatic phasing
  • :refit: the zero-order phase fitted with the first-order phase fixed at the series median, where automatic phasing failed or gave an outlying first-order phase
  • :neighbours: the zero-order phase of the neighbouring experiments, where the refit failed too, or where the zero-order phase was far from the rest of the series (see fixphases!)
  • :none: no phase could be found for any experiment in the series
  • :pdata: PHC0 and PHC1 from the experiment's processed data
  • :given: passed in, or read from a processing.csv

phase is :auto, :pdata, a vector of (p0, p1) pairs, or the path of a processing.csv written by an earlier analysis. Phases are found once; changing the line broadening reprocesses with them, since an exponential window does not change the phase.

NMRAnalysis.PeakTrack1D.SpectrumSeries — Type
SpectrumSeries(shifts, intensities, noise, sources, experiments; nucleus="1H", title="",
               bf=NaN, bf1=NaN, xi=NaN)
SpectrumSeries(spectra)

The data behind the stack: a shared chemical shift axis (ppm), the real intensities with one column per plane, the rms noise of each plane, the file each plane came from, and the index of the experiment each plane belongs to. A pseudo-2D experiment contributes several planes with one experiment index, which is what lets it be processed with one phase.

For referencing across nuclei it also holds, for each plane, the frequency of 0 ppm on its axis bf (Hz, which moves with the processing reference SR), the spectrometer's base frequency for the nucleus bf1 (Hz, from the acquisition parameter BF1, which does not), and the nucleus's Ξ ratio on the DSS scale, each NaN where unknown.

Built from a vector of processed spectra, 1D or pseudo-2D, whose shift axes must agree. Intensities and noise are divided by NMRTools' scale(spec) (number of scans × receiver gain, and the sample concentration where one is recorded), so that experiments recorded with different settings can be compared. The noise of each plane is NMRTools' whole-spectrum estimate (spec[:noise]), or where that is missing a robust estimate from the plane itself.

NMRAnalysis.PeakTrack1D.fixphases! — Method
fixphases!(phases, phasing, fids; window, zerofill, solvent) -> (phases, phasing)

Repair the phases of a series where automatic phasing failed (nothing) or went astray, using the rest of the series.

Residual first-order phase comes from the acquisition (the digital filter's group delay, the pre-scan delay, the excitation pulse) and not from the sample, so across a series recorded with the same parameters it barely varies, while the zero-order phase follows the receiver, the tuning and the temperature. A phasing that has settled on a wrong first-order phase, getting one line right and another wrong, therefore stands out from the series median (see p1outliers), and its zero-order phase is fitted again with the first-order phase fixed at the median.

The zero-order phase follows the sample, but within a series it varies by tens of degrees at most, so one far from the rest (see p0outliers) has been phased by the wrong feature, often settling near the opposite sign, when a single line is too broad or weak to dominate the fit. It takes the zero-order phase of its neighbours in the series, with the first-order phase at the median.

Automatic phasing fails outright when a spectrum has no line strong enough to phase by, which happens to a single line broadened by exchange near a pKa or a binding midpoint. Its zero-order phase is then fitted the same way at a lower signal-to-noise threshold, and failing that taken from the neighbouring experiments in the series.

NMRAnalysis.PeakTrack1D.peaktrack1d — Function
peaktrack1d(expts; process=true, lb=1.0, zerofill=2, solvent=:auto, phase=:auto,
            labels=String[], reference="reference", refshift=0.0, coordinates=nothing,
            peaklist=nothing, radius=8, snr=5, gain=2, colormap=nothing,
            size=(1200, 850)) -> PeakTracker
peaktrack1d(spectra; kwargs...)
peaktrack1d(fids; lb=1.0, zerofill=2, solvent=:auto, phase=:auto, kwargs...)
peaktrack1d(previous::PeakTracker; kwargs...)

Follow the positions of peaks across a series of 1D spectra, drawn as a stack. Each peak is a multiplet of one or more lines: pick each line by painting along its trajectory, then group the lines of a multiplet together. A multiplet's shift in each plane is the mean of its lines' shifts. One multiplet, shown first, is the chemical shift reference: once it is picked in every plane, the spectra can be aligned to it, and every shift is also reported referenced to it.

The window blocks until it is closed, and the analysis is returned. Show it for a table of multiplet centres, copy every line's shifts with clipboard(p), get every pick with planeresults(p), or reopen the window with peaktrack1d(p). Save writes the output folder named under the plot, and Load restores the picks saved there.

Arguments

  • expts: an experiment folder or number, or a list or range of them (e.g. 11:42), relative to the working directory. Each may be 1D or pseudo-2D.
  • spectra: processed spectra, as one NMRData or a vector of them, sharing one chemical shift axis.
  • fids: time-domain data from loadfid, as one NMRData or a vector of them.
  • process: for expts, process the raw data (true, the default) or load the processed spectra in pdata/1 (false).
  • lb, zerofill, solvent: exponential line broadening (Hz), zero-filling factor, and solvent suppression as for NMRTools' autoprocess, when processing. The line broadening can be changed afterwards with the slider under the plot.
  • phase: when processing, :auto to phase every experiment automatically, :pdata to take PHC0 and PHC1 from its processed data, a vector of (p0, p1) pairs in degrees, or the path of a processing.csv saved earlier. In a series of three or more, a first-order phase far from the series median is set to the median and the zero-order phase fitted again, and a zero-order phase far from the rest of the series takes its neighbours'.
  • labels: names of multiplets to create before picking; more are created as you pick.
  • reference: the name of the reference multiplet, picked in this analysis. Or, for ¹⁹F, ³¹P or another nucleus, a ¹H PeakTracker of the same samples with DSS picked: the shifts are then referenced indirectly to it on the IUPAC unified scale, using NMRTools' Ξ ratios, matching spectra one to one in order (see IndirectReference). The two must have the same number of spectra, recorded at the same field.
  • refshift: the shift (ppm) at which a picked reference is placed when aligning and referencing.
  • coordinates: what distinguishes the planes, one value per plane: a vector, a pair such as "pH" => pH, or a NamedTuple of vectors such as (; pH, T). Written beside every shift in the output.
  • peaklist: a peaklist.csv saved earlier, or an earlier PeakTracker, whose picks to start from. Each pick is placed exactly at its saved shift.
  • radius: the search radius (pixels) for snapping and for the brush.
  • snr: the smallest signal-to-noise ratio of a peak found by the brush. Picks placed by clicking are always accepted.
  • gain: the initial vertical scale; colormap colours the traces by plane.

Mouse

Only the current line responds; change it with the keys.

  • drag: paint a trajectory for the current line. In every plane the brush crosses, the tallest peak whose maximum lies inside the shaded area, within that plane's strip of the stack, is picked. Narrow the brush with [ and ] to keep a strong neighbour out.
  • click: pick the current line in the plane under the cursor.
  • drag a marker: move it along its plane. Right-click a marker: delete it.
  • shift-drag: erase the current line's picks under the stroke.
  • scroll: zoom chemical shift. Right-drag: pan. Ctrl-click: reset the view.

Clicked and dragged picks snap to the tallest point within the search radius; m turns snapping off (for overlapped peaks), and holding shift does the opposite of the setting.

Keys

  • ← →: step through the lines, multiplet by multiplet, to the vacant slot at the end, where picking creates a new multiplet. 0-9: select a multiplet; 0 is the reference, which can't be selected when it comes from a ¹H analysis.
  • r: rename the current multiplet (type, then enter; escape cancels).
  • g, then click a marker: join that line's multiplet to the current one. u: move the current line out into a multiplet of its own. d: delete the current line.
  • a: align the spectra to the reference, once it is picked in every plane. This changes only the display; shifts are always stored as measured.
  • ↑ ↓: vertical scale. [ ]: search radius. m: snapping. backspace: undo.
  • s: save the analysis to the output folder. f: save a figure of the region shown there, saving the analysis first if it hasn't been saved there from this window. q: quit.

Examples

p = peaktrack1d(11:42)
p = peaktrack1d(11:42; process=false)               # the processed spectra instead
p = peaktrack1d(11:42; peaklist="out/peaklist.csv") # carry on from a saved analysis
p = peaktrack1d(p)                                  # reopen

h = peaktrack1d(11:42)                              # ¹H, with DSS picked as the reference
f = peaktrack1d(51:82; reference=h)                 # ¹⁹F of the same samples, on DSS
clipboard(p)

See also peaktrack2d for 2D spectra.

NMRAnalysis.PeakTrack1D.summaryseries — Method
summaryseries(p, line) -> NamedTuple

What the summary panel shows for the multiplet holding line, against the first numeric coordinate or the plane number: the shift of each line and the multiplet's centre, and the height of each line. NMRAnalysis.PeakTrack1D.track — Method
track(s, v, pts, r, scale; snr=5) -> Vector{Pick}

The peaks painted by a brush of radius r pixels drawn through pts. Each plane owns the strip between its baseline and the next one up; in each plane the brush crosses, the tallest local maximum whose position lies inside the shaded area within that strip is picked, ignoring maxima below snr times the plane's noise. Narrow the brush to keep a strong neighbour out.
